- [Original input file hashes](research_input_sha256.json) cover all 413 research-completion files before publication.
- [Release contract](release.json) pins five permitted old navigation/ignore edits, original/public hashes, and the single non-scientific private identity-snapshot omission. Original document bytes are in [original_documents.zip](original_documents.zip); the private identity original stays local, and [public_delivery_state.txt](public_delivery_state.txt) is explicitly labelled.
- [Independent raw-window recomputation](recalculated/raw_recomputed.json), [paired aggregate effects](recalculated/paired_aggregate_effects.csv), [action denominators](recalculated/action_denominators.csv) and [cost definitions](recalculated/cost_definition_check.json) verify published numbers from saved ticks. - Frozen original reports, protocol, scientific sources, data, models, caches and original release evidence retain their bytes. Their original “uncommitted” and “all historical files unchanged” statements are time-scoped study evidence. This publication separately lists five current document/ignore edits; it does not claim all 3,662 baseline files remain unchanged after navigation updates.
- Runtime adapters execute the old numerical verifiers without editing old expected hashes. New receipts go into independent check directories. Saved-trace rerendering checks all three GIFs without new environment ticks; actual-player inspection remains not performed.
- `checks/commands.json` records actual commands, exit codes and test counts. Logs are labelled public copies when machine-local paths are redacted, with original/public digest mapping. Early failures, if any, remain separately recorded.
- `payload_manifest.csv` lists actual added/modified publication paths with SHA-256 and Git blob IDs; `manifest_scope.json` explicitly excludes itself and the manifest to prevent self-reference. Post-commit/remote receipts remain local `.tmp` files; Git commit/tree IDs cover the self-excluded manifest files.
