# Latest studies publication evidence

This release publishes **Boundary information and learning-rate stability** and **Short-horizon planning with learned terminal values** from saved evidence. Publication performs no formal training and no complete held-out environment replay.

- `experiment_input_sha256.json` snapshots the actual original source/config/test/data/model/report files before publication editing. It is not based on the previously reported 980/460 manifest counts.
- `release.json` lists exact permitted documentation changes and exact non-core omissions. `original_documents.zip` preserves original README/.gitignore bytes. Current documents and archived originals are both checked against their distinct digests; no old expected experiment hash is rewritten.
- `public_transcripts/` contains conspicuously labelled, path-redacted copies of six failed local transcripts/build attempts. Original digests and byte counts map each copy to the original retained locally. Four PDB/LIB compiler intermediates are omitted. The frozen DLLs, C11 sources, complete checkpoints, models, values/caches, results, protocols and prior acceptance evidence are retained.
- Frozen protocol/runtime metadata retains research-related workspace/toolchain paths to preserve evidence bytes. The scan found no tokens, private keys or unrelated personal records; the only email is the explicitly authorized public Git noreply identity. No virtual environment, toolchain distribution, Python/compiler cache, bytecode or ad-hoc temporary duplicate is included. The planning `cache/` directory contains frozen scientific policy/value artifacts required by the published protocol, so it is retained. Existing inventoried validation reconciliations are frozen acceptance evidence, distinct from new checker scratch files under `.tmp/`, which are not uploaded.
- `recomputed_results.json`, comparison CSVs and `paired_improvements.csv` are recomputed from per-window integer counts. Learned-model/Hybrid SD is sample SD across five models. Pure controllers remain one instance without a fictitious training SD. Each research uses its own holdout and baseline.
- `checks/` contains actual command results, exit codes, test counts and read-only artifact-verifier receipts for this publication. Machine-local raw logs stay under `.tmp/`; public receipts use portable command names and record the original log digest.
- `payload_manifest.csv` will list every actual added/modified payload path, byte count, SHA-256 and Git blob ID except itself and `manifest_scope.json`. The scope file documents these two unavoidable exclusions. Files generated after the committed manifest, including post-push validation, are local receipts and are not claimed to be part of that commit.

The explicit adapter is [aimrl/latest_publication.py](../../aimrl/latest_publication.py). It only acknowledges reviewed documentation originals and named non-core omissions. Missing/changed core data or models fail closed. It filters omitted rows only after validating their release record, and redirects verification receipts so previous frozen results are not rewritten. All original mathematical and numerical checks continue to execute.
